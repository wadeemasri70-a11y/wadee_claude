# AWAN — استوديوهات أوان للدوبلاج

موقع تعريفي من صفحة واحدة لشركة **أوان للدوبلاج**: مشهد ثلاثي الأبعاد متحرك،
حركة مرتبطة بالسكرول، ومعرض أعمال تفاعلي. عربي (RTL) مع تبديل فوري للإنجليزية.

A single-page site for **Awan Dubbing Studios**: an animated 3D scene,
scroll-driven motion, and an interactive works gallery. Arabic (RTL) with a
one-click switch to English.

---

## التشغيل / Running

الموقع HTML و CSS و JavaScript صرف — بدون build ولا مكتبات خارجية.

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

للنشر: ارفع المجلد كما هو على أي استضافة ثابتة (Netlify, Vercel, GitHub Pages,
أو استضافة عادية عبر FTP).

## البنية / Structure

```
index.html            كل المحتوى والنصوص (عربي + إنجليزي)
assets/css/style.css  التصميم، الحركة، النسخة الموبايل
assets/js/scene.js    طبقات الكانفاس: حقل الصوت 3D، الغبار، الإكوالايزر
assets/js/main.js     الستارة، المؤشّر، السكرول، اللغة، الفلاتر، الميلان 3D
assets/img/           مكان صور البوسترات (فارغ حالياً)
```

## الحركة ثلاثية الأبعاد / The 3D motion

`assets/js/scene.js` فيه ثلاث طبقات كانفاس مرسومة كلها بالإيد:

1. **حقل الصوت في الهيرو** — شبكة موجات بإحداثيات x/y/z، تدور حول محورَي Y و X
   ثم تُسقَط إسقاطاً منظورياً (perspective projection)، مع «أصوات» تدور في
   مدار حول المركز، وذرات ضوء، وتوهّج على قمم الموجة.
2. **الغبار الذهبي** — طبقة ثابتة خلف الصفحة كلها تتحرك ببطء وبعمق مختلف
   (parallax) مع السكرول.
3. **الإكوالايزر** — الأعمدة خلف قسم «فلسفتنا»، ترتفع كلما اقترب القسم من
   منتصف الشاشة.

لا WebGL ولا أي مكتبة، فيعمل على كل المتصفحات والأجهزة القديمة ولا يستهلك
البطارية. المشهد يتوقّف تلقائياً عندما يخرج من الشاشة أو عند تبديل التبويب.

- **السكرول** يرفع اتساع الموجة، ويميل الكاميرا، ويضيف ميلاناً خفيفاً حسب سرعة
  التمرير.
- **حركة الماوس** تدير المشهد وتميله.

عناصر ثلاثية الأبعاد أخرى بالـ CSS: بطاقات الخدمات والأعمال وبطاقات «من نحن»
تميل مع الماوس (`.tilt`)، بطاقات «كيف نشتغل» تأخذ عمقاً ودوراناً حسب موقعها من
منتصف الشاشة، وغرفة التسجيل مبنية بـ `transform-style: preserve-3d` وتدور مع
السكرول.

## الحركة أثناء السكرول / Scroll choreography

| المكان | ما يحدث |
|---|---|
| البداية | ستارة سينمائية مع عدّاد تحميل، ثم تنفتح لأعلى وأسفل |
| الهيرو | العنوان يصعد كلمة كلمة من خلف قناع، والموجة تتفاعل مع السكرول |
| الشريط المتحرك | سرعته وميلانه (skew) يتغيّران مع سرعة تمريرك |
| «من نحن» | الفقرة تُضاء كلمة كلمة، والأرقام عدّادات تبدأ عند الظهور |
| الخدمات | الأيقونات ترتسم بخط متحرك عند ظهور البطاقة |
| «فلسفتنا» | إكوالايزر خلف النص يتنفّس مع اقترابك منه |
| الأعمال | لمعة تمرّ على البوستر، والمؤشّر يتحوّل لزر «استمع» |
| «كيف نشتغل» | القسم يثبت (sticky) والخطوات تتحرك أفقياً بعمق ثلاثي الأبعاد |
| الاستوديو | الغرفة تدور مع نزولك في الصفحة |
| كل الأقسام | ظهور تدريجي، شريط تقدّم أعلى الصفحة، وشريط تنقّل يختفي عند النزول |

**مؤشّر مخصّص** (على الأجهزة ذات الماوس): نقطة تسبق حلقة تتأخّر خلفها، تكبر فوق
الروابط وتتحوّل لزر مكتوب فوق بطاقات الأعمال. والأزرار **مغناطيسية** تنجذب
للمؤشّر عند الاقتراب.

كل ذلك يُلغى تلقائياً لمن يفعّل `prefers-reduced-motion` في نظامه.

## كيف تعدّل المحتوى / Editing the content

### النصوص واللغتين
كل نص قابل للترجمة يحمل خاصيتين في `index.html`:

```html
<h3 data-ar="الدوبلاج" data-en="Dubbing">الدوبلاج</h3>
```

عدّل الثلاثة معاً (`data-ar`، `data-en`، والنص الظاهر بينهما). زر اللغة في
الشريط العلوي يبدّل بينهما ويحفظ الاختيار في المتصفح.

### الأعمال
كل عمل بطاقة `<article class="work" data-cat="drama">` داخل `#workGrid`:

- `data-cat` يحدّد الفلتر الذي تظهر تحته (`drama` `anime` `doc` `ad` `rev`)،
  ويمكن وضع أكثر من فئة مفصولة بمسافة.
- `--c1` و `--c2` لونا البوستر المؤقّت.
- لوضع بوستر حقيقي: راجع `assets/img/README.txt`.

### الألوان
كلها متغيّرات في أول `style.css` تحت `:root` — `--gold`، `--cyan`، `--bg` …

## ملاحظات قبل النشر / Before going live

- **قسم الفريق غير موجود** في هذه النسخة عن قصد (لا صورة فريق)، واستُبدل بشريط
  أرقام: عدد المواهب الصوتية، اللغات، ساعات الدبلجة، سنوات الخبرة.
- **الأرقام في قسم «من نحن» تقديرية** (٤٠٠ موهبة، ٨ لغات، ١٢٠٠ ساعة، ٥ سنوات) —
  صحّحها من `data-to` في `index.html` قبل النشر.
- **بطاقات الأعمال نموذجية** وتصف أنواع الأعمال لا عناوين بعينها؛ ضع العناوين
  والبوسترات الحقيقية مكانها.
- **بريد التواصل `info@awan-group.com` مؤقّت** — بدّله بالبريد الرسمي في قسم
  «تواصل» بآخر `index.html`.
- الخطوط من Google Fonts (Tajawal + Space Grotesk)؛ إن أردت الموقع يعمل بلا
  إنترنت خارجي، نزّل الخطوط محلياً وبدّل رابط `<link>`.
